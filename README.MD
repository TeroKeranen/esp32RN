
# ESP32 Project with React native

## Introduction
In this project, I use an ESP32 device that can be connected to a Wi-Fi network. Once connected, it can be controlled using this application. The project includes a Node.js/Express backend.

## Installation
1. Run the following command to install dependencies:
    ```sh
    npm i

2. You need an .env file

3. Create an expo build and install APK/IPA manually:
    ```
    eas build --platform android
    ```
    eas build --platform ios
